# FashionStore — Pipeline de Datos para E-commerce de Moda

Proyecto de Business Intelligence orientado a la preparación, transformación y modelado de datos utilizando PostgreSQL como capa principal y Power BI como herramienta de visualización.

## Arquitectura

Archivos CSV/XLSX → STAGING → Limpieza SQL → Modelo Relacional → Vistas SQL → Power BI

## Tecnologías

- PostgreSQL
- DBeaver
- Power BI
- Power Query
- SQL
