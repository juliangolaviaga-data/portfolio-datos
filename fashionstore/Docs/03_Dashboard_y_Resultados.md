# Dashboards y Resultados

## Dashboard Ejecutivo

Objetivo: brindar una visión gerencial del negocio.

Indicadores:

- Total ventas
- Total órdenes
- Clientes activos
- Ticket promedio
- Tasa de cancelación
- Producto TOP
- Ventas por categoría
- Clientes por segmento
- Clientes por ciudad
- Órdenes por estado

## Dashboard de Ventas

Objetivo: seguimiento operativo y análisis temporal.

Indicadores:

- Detalle de órdenes
- Órdenes por estado
- Método de pago
- Ventas mensuales
- Participación de ventas por producto

## Medidas DAX utilizadas

- Total Ventas
- Ventas MoM %
- Ventas MTD
- % Sobre Total 3
- Ticket Promedio
- Tasa Cancelación

## Resultado del proyecto

El modelo permite identificar categorías con mayor facturación, productos líderes, comportamiento de clientes por segmento, evolución mensual de ingresos y desempeño de los métodos de pago.
